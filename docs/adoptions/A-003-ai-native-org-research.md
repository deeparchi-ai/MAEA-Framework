# A-003: 头部 AI 企业组织研究（Accenture / OpenAI / Anthropic / Sierra）

**状态**：已吸收·已实现  
**日期**：2026-07-18（台账建档）  
**来源类型**：行业研究（企业组织架构实证）  
**权威出处**：Accenture 2025 年组织重组公开信息；OpenAI、Anthropic、Sierra 公开组织资料

---

## 吸收了什么

| 来源观察 | MAEA 对应 | 说明 |
|---------|-----------|------|
| OpenAI / Anthropic 均无独立运维部 | 运维职责并入 do-ops 单 Agent | 自动化程度足够高，不设运维组织层 |
| Accenture 2025 取消 5 个行业事业部 | 行业知识由数据与模型承载 | 五域中不设行业域 |
| Sierra 的客服 Agent 交付形态 | 交付域（do-*）职责边界 | Agent 直接面向业务结果 |
| Anthropic 的垂直化玩法（Claude for Legal） | Legal Agent 集群（按需启停） | 垂直 Agent 而非通用 Agent |

## 主动舍弃 / 未吸收

| 来源观察 | 为什么不吸收 |
|---------|-------------|
| 大厂的多层管理跨度（EM 层） | 3–5 人 AI 原生组织无中间管理层 |
| 大厂的行业事业部编制 | 行业知识由数据/模型承载，不设组织 |
